# Security policy

TrillionniumOS Desktop is pre-release software. Do not treat the repository,
self-check, or development images as production-safe.

Report vulnerabilities privately through the repository's GitHub security
advisory interface. Include affected commit, threat scenario, reproduction,
expected boundary, and whether secrets or external effects may have occurred.
Do not place live credentials, private keys, user data, or undisclosed exploit
details in public issues.

Security-sensitive areas include trusted origins/shell, AgentPort identity,
PageOwner arbitration, capability permits, browser/network sandboxing, signed
apps, receipts, updates, rollback, and release claims.
