# Typed original request Core

P2A adds one nongeneric simulation Core and one thin Servo actor. The Core
privately consumes a fixed typed endpoint and a moved genuine P1 request
Binding. Only that Binding and its same-service verifier select the actual
Agent, snapshot and root-approved principal. Its original `with_original_pair`
supplies the live default-proc Control/Agent and original deadline. No caller
principal, proc source, runtime, future Instant, permission boolean, raw actor,
registrar, `Deref` or weaker request-handler implementation is accepted.

The two constructors prepare their first request. Later preparation consumes a
fresh same-service Binding only when previous preparation has been retired and
the engine and actor have no active, prepared or uncertain work. The owning
Binding remains inside Prepared and Handled state through the bridge's actual
final-forward post Control/Source samples. Early retirement refuses while work
is pending; dropping or cancelling an escaped callback cannot establish that
an effect disappeared. Unknown work closes the same pair permanently and never
creates a fresh journal, owner, Source or request clock.

The private scope retains the entire bounded original BrowserRequest,
canonical bytes and digest, and separately the exact runtime envelope. The
old fixed EngineThreadRuntime removes `deadline_unix_ms`; its Create mode is
headed. P2A admits only headed original Create and clears only the wall-clock
field in the runtime domain. Both domains keep exact session, generation and
operation. Capture compares complete canonical pending bytes against that
runtime domain, as well as the exact engine Arc and private nonce. Request ID
text alone never authorizes a match or a later callback. The original canonical
container is rechecked inside the captured scope through completion and final
forwarding; later registration does not replace it.

The private fixed ServiceScopedRuntime waits for this scope's actual bridge
final post before returning a buffered reply to the legacy actor. The legacy
actor's unconditional cancellation retirement therefore follows the bridge
post samples. Core independently waits for the same captured completion before
accepting a known return. Both waits use the original remaining budget and full
Source checks; cancelled, expired, retired or closed state refuses and retains
uncertainty. Only the real bridge writes the finished flag. Physical send,
callback queue or a caller flag cannot substitute for that post. Completion
retains its original scope even after a later genuine preparation selects a
new private runtime scope. This is bounded sampling, not an atomic effect or a
durable/wire delivery claim. PageAct remains explicitly refused.

DispatchContext is corresponding input. Its hash is recomputed from the full
request, peer must equal the genuine Agent, effect class must equal the request,
and effective deadline must be no later than the actual original P1 ceiling.
`accepted_at` is checked as bounded caller context; P1 does not supply or certify
that timestamp. P2C must actually decode the original authenticated socket and
construct the actual transcript context. A text hash or public context cannot
prove that wire provenance on its own.

Fixed session continuity uses the same OnceLock and actual P1 creator/PID
namespace checks before mutable registration access. Idle Source/Owner checks
do not retain the first request's 20-second lifetime as service lifetime.
Per-request dispatch still uses its original Instant and closed immutable
operation/URL bounds. The original APIs, test bodies, PIN, profiles and all
5/20/60-second cases remain byte exact through reviewed complete inverses.

This module adds no journal or raw ReceiptLifecycleObserver API. P2C still
needs the unique owning Requests, actual original wire path, serial admissions,
typed lifecycle/writer and complete managed-chain quarantine of active,
prepared and uncertain results. Local known return, callback queue and physical
send are not durable success or delivered wire. Denial/Drop closes locally and
does not clear journal ambiguity or retire the entire ServiceSource.

The versioned contract records actual APIs and every private function in this
finite Source successor. Its checker proves Source correspondence only. The
five pure canonical unit cases carry no forged Binding or Source, and the four
new compile-fail examples remain unexecuted until a separately authorized Rust
window. P3 must place these proofs inside real native effects and qualify the
same Servo/WebView across fresh original requests and native60. P4 must qualify
the actual installed route. Default installed activation remains disabled.
