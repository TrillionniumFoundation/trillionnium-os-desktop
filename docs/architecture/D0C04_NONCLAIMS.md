# D0C-04 non-claims

The presence of the connected AgentPort source does not establish any of the
following:

- an enabled or reachable product listener;
- a systemd service identity or cgroup binding;
- BrowserActor execution;
- Servo compilation or runtime integration;
- a visible page, navigation, pointer, keyboard or IME event;
- a system capability grant;
- an external web effect;
- a bootable Debian image;
- beta or release readiness.

Only direct evidence at the corresponding later gate may establish those
claims.
