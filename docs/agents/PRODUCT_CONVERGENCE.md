The selected release candidate uses the preedit profile because the default SDK
does not contain its IME transaction/undo and duplicate-focus fixes. Its path
lock is generated by Cargo and committed only in the explicit release worktree
containing these product fixes. The development branch keeps the normal
original Git SDK and its 54-file bundle. The clipboard profile is a separate
candidate; preedit does not advertise PasteText. Each actual package must bind
one complete source/lock/profile combination and acquire fresh execution
evidence. Historical preedit results do not qualify this new release.
The stable-document 512 KiB store on PR #268 is a different format even though
its schema integer is also 1. Never rename it into this store or convert its
receipts into an execution grant. Preserve its original owner until every
pending operation is reconciled; any future importer requires an explicit,
separately reviewed text-only contract.

## Real Linux product closure

Use the existing [text adapter](../../services/hepta-session-host/TEXT_SESSION.md)
and original Hepta
[native Root launcher](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/489f7096b0e5754968a30fa4477bb4417d24834f/codex-rs/hepta-agentd/NATIVE_TEXT_SESSION.md).
The trusted deployment must supply its original Root configuration, live
daemon registration and pidfd, and an already authenticated human native
profile for the existing App Server thread. Provider configuration remains
owned by that original Agentd. An OS login, local model gateway or a socket
path cannot stand in for that human-session/issuer registration.

`diagnose-native` deliberately does not claim production readiness. Only the
original open-only `launch-native` path may use those established inputs to
launch the exact trusted distribution ELF. Retain its actual original-thread
input/reference, model stream, reviewed effect, original FinalUse and writer,
exact application target/revision, independent readback and durable terminal.
The named Write note action currently compiles literal document content; its
separate Objective path is not evidence that an arbitrary model tool invoked
Notes through the same thread. That integration must retain the original tool
and effect owners and acquire its own end-to-end evidence.

The recovery matrix then repeats with a lost reply, application exit, Session
exit, original owner exit, reconnect, revocation and a competing edit. Every
unknown result retains its original operation identity; independent observation
must not dispatch a replacement effect. The test-authority process recipe and
real production run must be recorded separately.

original signer, actual installed APK/helper, live original owner and the exact
window/node/generation before a bounded set-text/readback operation. Equal
observed text without the original causal receipt remains indeterminate.

does not transfer an older kernel result to the new pair. Full F1, production
G2, exhausted-resource recovery, display/input and physical drivers keep their
own same-source execution requirements in the
[current capability table](../CURRENT_CAPABILITIES.md).
