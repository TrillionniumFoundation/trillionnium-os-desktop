# Ktest private BIOS and QEMU resource entry

The ktest recorder previously ignored the project's private BIOS/data selections and always read `/usr/share/seabios/bios-256k.bin`. On this configured host that file is absent. The retained exact-baseline before control fails both positive CLI tests with that FileNotFoundError despite valid private selections; no guest ran.

The recorder now imports the ordinary recorder's `select_bios` and `select_data_directory` from its absolute source path. It reuses the same validation rather than maintaining another implementation. An explicit nonempty absolute regular BIOS file and nonempty absolute existing resource directory select the actual fixed-profile BIOS and one -L. Empty, relative, missing and nonregular selections fail before QEMU's version probe or launch. An incoming OSDK -L conflicts with explicit DATA selection and is rejected through the shared selector before other OSDK extras are discarded.

Original OSDK arguments, the fixed argument list before selection, selection provenance and actual argv are retained. Selected BIOS, kernel and optional initrd digests use the normal stable regular-FD capture. The fixed q35/TCG/CPU max/1-vCPU/512-MiB profile remains fixed even when incoming OSDK extras request different devices or resources. Optional initrd remains optional. No immutable ktest snapshots are added; the existing source-artifact model and unchanged checker remain in effect.

run.py now records the normal selector source among environment input hashes. The existing lifecycle fixture adds one source-file copy to represent that declared dependency; no check or ownership rule is relaxed. The encoded Rust flags early guard, process-group cleanup and locked source/OSDK contracts are unchanged. Normal recorder and kernel/OSTD/OSDK sources are not modified.

Actual host regressions passed under **both -I and -I -O**:5 private CLI tests,12 result-checker tests and17 lifecycle tests, **68 successful test executions total**. The old-wrapper two-test before control is a separate expected failure. Private tests invoke the actual production CLI with a disposable fake QEMU; they exercise paths containing spaces, optional initrd, fixed-profile preservation, four invalid BIOS values, four invalid data values, incoming-L conflict and malformed OSDK required arguments. Every invalid selection has no version/launch marker. All four retained successful CLI invocations observed the standard system BIOS file absent before invocation. Tests do not modify /usr and remain usable on hosts where the standard BIOS is present.

No Rust compilation, real QEMU guest or upstream kernel regression ran for this package. A fake fixture raw33 is not native kernel acceptance. Root will run real OSTD/core tests separately from an isolated worktree after source publication.

source/ retains exact baseline controls, unchanged normal selector/checker dependencies, tested candidates and patch. logs/ retains all complete final suites, before failure, command/environment/exit and stable-source receipt. actual-cli-fixtures.tar.gz retains raw fixture outputs with member size/SHA256/mode in raw-members.json. Existing evidence phases are unchanged. SHA256SUMS covers every retained file except itself.
