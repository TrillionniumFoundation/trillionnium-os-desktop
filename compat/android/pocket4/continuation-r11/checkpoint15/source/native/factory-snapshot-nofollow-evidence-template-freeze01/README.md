# Fixed NOFOLLOW snapshot evidence reader templates

This is a source-only derivative of the ordinary snapshot evidence reader. It changes only the fixed NOFOLLOW runtime root, two unique operation keys, and the result-template hash binding. The complete two-log held-file body is byte-for-byte unchanged. It starts no fixture, factory service, namespace or Android task and never dispatches its generated requests.

The result request can be generated only after Root supplies the actual terminal result byte length and SHA-256. The two-log request consumes the complete original runtime result bytes and binds only `snapshot.stdout` and `snapshot.stderr` at the fixed NOFOLLOW root. The original result is read again before and after both logs. Regular file, root ownership, non-writable mode, link count, canonical path, O_NOFOLLOW open, held/named identity and full-byte hash checks are retained. The result limit is 131072 bytes; the fixed log limits are 131072 and 32768 bytes.

The request uses sudo only for the protected read, with 25% CPU, 128 MiB and 30 seconds. No root capability changes, replay, source edits, files written, child creation, Main actions or current runtime qualification is implied. Swap capping is not claimed. Source-only templates have no actual result binding and must not be dispatched as a test substitute.

The independently frozen five-case NOFOLLOW runtime and build are unchanged. Their current acknowledgment/result status remains with Root; this package performs no reconciliation or remote call.
