# O_NOFOLLOW actual-ELF runtime template 01

This source-only runtime template retains the ordinary snapshot runner's 21 unchanged functions, including held ELF execution, fork/PIDFD waiting, exact child cleanup, fixed root staging, UID/GID61179 availability checks, source/authority/tool/library before-and-after checks, and the same resource gate. Only matching-build qualification, the five-case output contract, fixed identities/paths and scope change. There is no runtime request until the matching build receipt is available and passes its frozen predicate.

The matching build must contain six complete translation units with actual dependency observations, two held output artifacts, an exact five-case default PLAN, and the standalone V2 factory default-disabled result. The runtime executes only the held snapshot control ELF once. It never executes the standalone factory with inherited descriptors or starts a listener/service.

The fifth real fixture case requests O_NOFOLLOW from the kernel, compares actual F_GETFL against the source, duplicates the output descriptor, verifies that F_SETFL cannot clear the immutable bit, changes and restores O_NONBLOCK through the duplicate while comparing the native source, and verifies the same memfd readlink contract before and after child transfer. The original four snapshot cases remain required. Exactly five successful case records plus one aggregate, five direct children normally reaped, zero nested/forced/unreaped children, actual snapshots true and policy/service false are necessary.

The fixed root factory's existing CAP_DAC_READ_SEARCH and kernel file-handle support remain prerequisites to observe. No capability, UID0 policy, filesystem, namespace, seccomp or Main transition is changed to make the helper work. The inherited V2 ELOOP and local EPERM evidence are preserved. A successful owned mechanism would still not establish early platform policy, trusted fork-role integration, ART/guest adapter correctness, or deployment readiness.

The budget remains CPU50%, MemoryMax256MiB, nice15, outer120s/inner90s, held harness45s with the fixture's internal30s bound. SwapMax is observed only. The generator preserves raw actual receipt bytes and replaces a single SHA placeholder; no actual build/result/hash or PASS is invented in this freeze. Root owns dispatch and keeps ordinary O_RDONLY runtime first.
