# Bili native error format reader 02

Minimal successor to frozen reader 01. All five external file pins and the full 414-byte message pin are unchanged. It adds one producer-specific complete child error grammar, from the fixed service source, and six production parser controls. The independently constructed 126-byte fixed error line for task 873 exactly matches the earlier actual stderr second-line bytes/SHA.

Every typed report still requires full message-wrapper and ordered timing grammar. The complete stderr must agree with the stdout message. The known child line has its own prior actual pin. Unknown error text stays private. The reported condition is a different existing registration ownership; the reference source tests package mismatch OR Android display mismatch. This does not identify which field differed, the underlying cause, or the installed binary's source lineage.

The task number is a reported error identity, not cleanup authorization. Original launch failure/UNKNOWN is retained. No task retirement, input, launch, namespace entry, or child process occurs. Twenty-two pure controls run only when Root dispatches; no local execution is claimed.
