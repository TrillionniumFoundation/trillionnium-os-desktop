# Fixed Bili native error format projection

Five historical files are read under fixed full bytes/SHA pins; the original complete worker/command bindings and nofollow bounded Reader are preserved. The native response message has its separate actual 414-byte pin, and the entire stderr must equal the CLI prefix plus that complete message and one trailing newline.

Projection recognizes the complete known two-line wrapper, ordered timing-stage prefix and fixed task-launcher error class. Unknown child text is represented only by bytes/SHA. Labelled task numbers are diagnostic mentions, not task ownership or cleanup authority. No semantic producer-specific error grammar is currently admitted. Producer source and installed binary correspondence remains unverified. All original failure/UNKNOWN states remain unchanged.

Sixteen pure controls run before fixed reads. They have not been run or compiled here. The script spawns no child, enters no Android namespace, reads no private UI tree, and changes no files or tasks.
