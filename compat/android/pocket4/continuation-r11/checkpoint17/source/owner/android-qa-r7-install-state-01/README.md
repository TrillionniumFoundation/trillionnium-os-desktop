# R7 helper installation and no-automation state

This candidate binds complete actual R7 build and stage receipts. The original R6 install implementation is retained with the new package, paths, nonces, actual build/APK/signer pins, and rejection of the old R6 UID 10184. The R4 recorder and transport copies are exact.

One package-absence check includes uninstalled records and all users. Installation retains the original -R no-replacement flag and fresh owned staging directory. The helper UID comes only from the actual package-list result, followed by two exact installed-byte observations around one state invocation. No UiAutomation, app launch, playback input, permission or setting write is admitted. Main guards, held leases, one global action lock and precise owned staging cleanup remain intact. Failed or unknown installation is reconciled from fixed receipts, never retried automatically.

A separate future UI source requires the complete actual install receipts, installed identity and a fresh owned task. This source does not provide them.
