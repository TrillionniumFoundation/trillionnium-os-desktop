# CP14 native frozen-source allowlist

This index contains 88 UTF-8 files (4,750,421 bytes) from 11 already frozen packages. Every listed local file was read completely, checked for regular-file/no-symlink form and UTF-8 decoding, and matched to its frozen byte length and SHA-256. The Git root and package subtree hashes were independently recomputed from the actual file bytes. All 11 roots now exist as unreferenced Git objects in TrillionniumFoundation/trillionnium-os-desktop. No branch or PR was changed.

The comparison base is the 6,227-file CP13 delivery manifest, SHA-256 9384a0d78fdc4e27966b16b53f95872788670cc6486fa4a32bbad2f8aa414869. The new package paths are absent from that manifest; files whose bytes already exist at another CP13 path are explicitly marked in the allowlist. Historical source manifests are preserved byte for byte.

SOURCE_FILE_ALLOWLIST.json is the exact file/byte/SHA allowlist. SOURCE_TREE_INDEX.json maps each package prefix to its existing unreferenced Git root and package subtree. The index itself is a separate small source package, so its files are not included in the 88-file payload count.
