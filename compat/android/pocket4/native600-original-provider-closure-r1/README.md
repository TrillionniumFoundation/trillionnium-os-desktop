## Allocation observer

owned_allocation.py binds two non-overlapping owned roots with directory file descriptors. It binds the actual system-managed du alias and holds the resolved executable descriptor, hashes those held bytes, and rechecks named-path identity. It executes the held tool with only the two held root descriptors as operands. Child symlinks are not followed.

An allocation is accepted only from an exited and reaped command with exit code zero, empty stderr, and exactly two complete NUL-terminated output records for the exact operands. A narrowly recognized real disappearance diagnostic permits a bounded retry, never a partial or failed measurement. Three attempts share one 30-second deadline. Cancellation, resource checkpoints, four-megabyte log limits, final output bounds, root replacement checks, and owned-only timeout retirement remain mandatory. Failed attempts retain their real argv, return code, stderr, timeout, and reap evidence.
