# Owned native application qualification units

Calendar reminder and Gallery require different hard ancestor budgets. The shared
daemon cannot serve as both exact resource scopes, and an unbounded nested group
cannot satisfy their original leaf resource gates. This source delta adds two
finite installed qualification units. Their actual native controller owns the
original nested child and complete systemd cancellation scope.

The controller keeps the original source/release locks and runtime-plan dispatcher.
It observes the real PID 1 private connection, peer credentials and peer PIDFD;
queries the actual controller PIDFD invocation; and checks typed effective manager
commands, budgets, affinity, seven held host namespaces and final SIGKILL behavior
before and after dispatch. Only one exact current Calendar or Gallery plan is
accepted. No production HostPeerIssuer or Main qualification is constructed.

Normal assembly and the direct installer include the fixed templates; package
release becomes 22. The existing component baseline already binds every packaging
input, so this payload addition requires a complete package build. The templates
have no automatic enable target and do not start Android.
